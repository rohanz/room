# Room — implementation plan

Spec: `../specs/2026-09-09-room-design.md`. Order chosen so the riskiest piece (sync) is
proven first and every later step has something real to integrate with.

## Phase 0 — skeleton (sequential, by lead)
- npm workspaces monorepo, TS config, vitest, tsx. `packages/shared` with schema types,
  identity+colour, claim overlap, bus/claims helpers, doc accessors. Unit tests.
- `packages/server`: y-websocket server script + /health. Manual check.
- `examples/demo-repo`: tiny Python project (create_order handler + pytest), uv.

## Phase 1 — parallel (three subagents, each owns one package)
- **roomd**: seed/adopt/refuse logic, watcher, diff-apply, echo suppression, base tracking.
  Integration test with two temp git repos and in-process server.
- **room-mcp**: MCP server with tools, channel push, filtering rules, awareness status.
  Unit tests against in-memory doc.
- **web**: Vite app, CodeMirror + y-codemirror.next, claims gutter, sidebar, feed, notes.
  Manual + Playwright smoke if time.

## Phase 2 — integration (lead)
- `scripts/demo.sh` bringing up server + two clones + two daemons.
- `.mcp.json` + `.room.json` handshake. Launch two Claude Code sessions, walk the demo path.
- Fix what breaks. Record findings in docs/decisions.md.

## Phase 3 — polish (only if phase 2 is green)
- Claim range remapping with Y.RelativePosition. Conflict card in web. README with setup.
