## Limitations

- Measures observed tool routing, not successful completion of delegated work.
- 16 authored prompts, two trials each, one model and one fixture; not a calibrated real-world success rate or a Codex-host evaluation.
- Main matrix uses a frozen source snapshot whose room-workers skill still recommended native agents for read-only research; it nevertheless routed all explicit requests correctly. A separate two-trial check uses the final corrected skill.
- Eight original incidental trials were blocked before model execution by scaffold DNS failures and excluded; they were rerun against the same pinned local fixture and frozen plugin snapshot.
- Static Room mocks cause capped workflows; native Agent runs were terminated at configured time limits after routing was observed.
- Final spot-check is separate and is not added to the 32-trial matrix denominator.
