## New findings

1. **medium — a new worker inherits an old worker's owed messages.** The docs worker's first
   room_scope delivered three stale answers addressed to an earlier `rohanz+docs` worker (an earlier
   batch's), one telling it to update `doctor-entry.test.ts`. A reused tag reuses the participant name,
   and owed messages are keyed by name, not by worker session.
2. **low — room_claim clamps silently.** `room_claim to=561` on a 560-line file became 560 with no word.
3. **process — the skipwalk worker could not find the reported reason text.** The finding said
   "(N .gitignore)"; no roomd path emits that label. Human-paraphrased log lines cost a question round:
   quote logs verbatim in findings.
4. **medium (fixed here) — the hot-path throttle counted unchanged republications.** Found by skipwalk:
   every reconcile marked every changed file as published, so after five edits to one file any other
   changed file was "hot" and its next real edit waited 30 s. Only a real text change counts now
   (`packages/roomd/test/hot-path.test.ts`).
5. **low — roomd runs one `onDiskChange` per changed path in a batch** (skipwalk); not changed here.
6. **low — "[inbox N]" blocks precede tool replies,** so an `error:` line is not at the start of an
   error reply (refresh). Tool-text changes also need `npx tsx scripts/eval-mocks.mts`, which AGENTS.md
   does not say.
7. **low — the room_send budget had 17 characters of slack** before the refresh parameter (refresh
   trimmed two parameter descriptions to fit; no routing words touched).
8. **low — the PreToolUse hook says "Claim before editing" on files the worker already claimed**
   (notices). `roomagent` (`packages/agent`) keeps its own wake path, which the new solo gate does not
   cover; the web timeline still shows migrated 0.16 history.
9. **low — `tsc -b` in a worker leaves `dist/`, which the preview reports** as the worker's build
   output (skipwalk, notices). Harmless, but every preview names it.
10. **medium — a resumed worker's second room_done did not reach the lead.** notices was resumed with
    a follow-up, finished and called room_done (its log shows the report), but the lead's room_wait only
    said "1 worker still running (preview)" and room_state still showed the first report's summary. The
    lead found the second report in the worker log.
11. **low — an overlap that merges cleanly arrived as a CONFLICT notify.** notices' one-line edit in
    `messaging.ts`, near the lead's collected refresh changes, was reported as `CONFLICT … overlaps
    rohanz+notices's new claim`; it merged with no conflict. Useful as a heads-up, loud as a conflict.
