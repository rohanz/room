# Room 0.17.4 release validation

Status: release validation complete; fresh Flask rehearsal, independent Astra review, release CI, installed-plugin smoke and hosted deployment checks passed. Release: [v0.17.4](https://github.com/rohanz/room/releases/tag/v0.17.4).

The first [Flask fault rehearsal](2026-10-04-flask-fault-rehearsal.md) found that automatic relay reconnection reapplied launch-time `ROOM_SHARE=full` over a worker's later `intent` choice. A sibling then read a synthetic canary that should have remained unavailable. This was fresh republication, not stale-cache resurrection. Reasserting `intent` is recovery only and does not satisfy acceptance. The candidate checks below predate this newly exposed defect.

Real-process regressions failed before the correction: a separate observer read private text after relay takeover; a retained worker's new process reset saved intent to full; and a stale callback revived a cancelled automatic join. Automatic joins now remember the latest adopted session without cancelling the user's leave choice, and a worker's launch environment seeds its first sharing choice without overwriting later saved policy. Focused checks passed 42 tests across four files, plus three additional checks. A separate display regression failed before the change and all 28 shared-view tests passed afterward: a pending shutdown stop no longer makes a running worker appear stopped, and ambiguous process states remain explicitly unconfirmed. Astra independently accepted both patches. Full local confirmation then passed 3,516 tests across 321 files in 424.04 seconds (`/tmp/room-0174-full-final.log`).

Typecheck, the full plugin build, server bundle build and repository hygiene check passed. Release-focused doctor, skills, tool-budget and hook suites passed 129 tests. The first sandboxed invocation could not listen on loopback or inspect parent processes; the unchanged suites passed when run with those capabilities available. Raw local log: `/tmp/room-0174-release-targeted.log`.

One final interleaving regression showed that `room_share` can persist a narrower choice while awaiting projection, before updating its session copy. `rejoinOptions` now reads the canonical policy store directly. The regression failed before the one-line correction; 31 sharing/join/compaction checks, selected automatic reconnect checks, typecheck and rebuilt plugin/server checks passed afterward. Astra accepted the correction. The final release commit must pass the entire updated suite in CI.
