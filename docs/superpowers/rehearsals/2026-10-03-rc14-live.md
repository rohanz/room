The first run's workers completed after reconnection, so it did not by itself
establish completion-during-outage behavior. A second, one-worker run forced a
45-second outage after its preview. Its actual `room_done` timed out reconnecting
and returned **completion report saved locally**, explicitly retaining claims and
saying the lead was not yet notified. The agent retried completion when the server
returned; the lead received its report and collected the exact artifact in 2.85
seconds. This verifies the live durable fallback response and subsequent recovery;
the automated regression also covers exiting with only that local report.

The harnesses ran in the foreground with deadlines and cleanup. All rehearsal
servers, workers and MCP processes exited. Temporary test credentials were removed.
Codex's temporary 0.17 install was restored to the normal 0.16.40 marketplace install;
the restored version was verified. Claude's installation was unchanged.
