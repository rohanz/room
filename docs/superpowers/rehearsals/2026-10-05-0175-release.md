## Post-publication CI termination

The documentation-only release commit `31c87437` failed [run 37229060468](https://github.com/rohanz/room/actions/runs/37229060468): 321 files and 3,449 tests passed, but the worker running `tools.test.ts` exited on SIGTERM. This run did not complete all checks and must not be described as green.

Local signal tracing found that `workers.test.ts` sent a real SIGTERM to synthetic PID 4243 when shutting down independent lead registries. The second lead has no in-memory handle for the other lead's worker, so it uses the fallback signal path. The injected fixture probe verifies the synthetic identity, but the unmocked signal function then targets the real OS PID. A regression test intercepted that signal safely and failed with `[4243]` before the correction. The failed CI log does not record the victim PID or signal sender, so this is a demonstrated test-isolation defect and a plausible cause of that CI termination, not proof of its exact sender.

The worker suite now routes fallback signals using its synthetic probe through the same fixture model as its liveness checks. Real-process tests retain the real signal path. The regression asserts that independent-registry shutdown never sends an OS signal to a fixture PID. No runtime source or installed package changes are required.

The isolated regression failed before the fix and passed after it; typecheck also passed. Complete-suite verification is required on the correction commit. Evidence: `/tmp/room-fixture-signal-before.log`, `/tmp/room-fixture-signal-regression.log`, `/tmp/room-signal-typecheck.log`.

The full signal trace also exposed a second fixture leak in the W8 stop-refusal test: its mock treated PID 8 as absent only for signal 0, allowing the SIGKILL escalation to reach the OS. That fixture now treats every OS signal to its synthetic PID as ESRCH. The complete worker suite passed 149 tests after the first correction; both affected cases passed together after the second correction. Evidence: `/tmp/room-fixture-signal-after.log`, `/tmp/room-fixture-signals-final.log`. Final full CI is tracked by the correction commit's GitHub checks.
