# Submission checklist

Deadline: _see hackathon portal_ (fill in once known, with timezone).

## Deliverables

- [ ] Project title
- [ ] Written description (problem, environment, what the agent does, why here; 150–300 words)
- [ ] Public GitHub repo — README has setup + run steps that work from a clean clone
- [ ] Two-minute demo video (see script below)
- [ ] Social media post tagging event partners (list partner handles here once known: _TBD_)
- [ ] Submitted in the portal before deadline

## Pre-record checklist

- [ ] `.env` not committed; `.env.example` complete
- [ ] Fresh clone → install → run works (test it, don't assume)
- [ ] Demo path run 3 times in a row without failure
- [ ] Failure path demoed once (agent declines / recovers gracefully) — it's scored
- [ ] Dead code and debug prints removed

## Demo video script (2:00)

| Time | Beat |
|------|------|
| 0:00–0:15 | The place: show the real environment, the user mid-task, the pain point |
| 0:15–0:30 | The agent shows up *there*. One sentence on why it can't be a chatbox |
| 0:30–1:20 | Core workflow end to end, real data, no cuts if possible |
| 1:20–1:40 | User control moment: confirmation, undo, or the agent refusing something |
| 1:40–2:00 | What's built, stack in one breath, repo link on screen |

Record the screen at the environment's native size. Narrate what the agent is doing while it does it.
